# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or accidental secret.
Use GitHub's private vulnerability reporting or a private Security Advisory in
this repository.

Include:

- affected version or commit
- reproduction steps
- expected and observed behavior
- potential impact

The project does not require API keys for its weather providers. A committed
credential, signing certificate, provisioning profile, private network name,
or user-specific configuration should be treated as an incident and removed
from both the current tree and Git history.
