# Tasks

Tasks are organized by lifecycle and share one four-digit ID sequence.

Invoke `lore-codex-tasks` before creating tasks, changing status, archiving
work, or spawning follow-ups.

## Directories

- `backlog/`: future work
- `active/`: work in progress
- `blocked/`: waiting on dependencies
- `archive/`: completed, canceled, or superseded work

Use a single Markdown file for a small task. Use a directory with `README.md`,
`notes/`, `worklog/`, and `sources/` for substantial work.
