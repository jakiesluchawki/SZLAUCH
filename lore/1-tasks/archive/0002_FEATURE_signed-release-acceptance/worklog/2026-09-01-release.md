## Pitfalls And Coverage Limits

- Codesign did not find an identity solely through `--keychain`; temporary
  search-list inclusion was necessary. No legacy keychain was revoked/reset.
- LibreSSL treats the same passphrase file used for both passin and passout as
  two input lines. Separate private passphrase files avoided that import issue.
- Cloud Developer ID export using an API key is subject to the Apple-reported
  limitation in https://developer.apple.com/forums/thread/776036.
- `CGPreflightScreenCaptureAccess` and `AXIsProcessTrusted` were false.
  No native pixel capture/automated click test or permission bypass was used.
- x86_64 app execution and an x86_64 system executable both reported
  `Bad CPU type in executable`; Rosetta was unavailable.
- Runtime checks ran on Apple Silicon/macOS 26. Physical Intel and older
  supported macOS remain untested.
- Live VPN, Wi-Fi/hotspot switching and sleep changes were not made on the
  active host connection. Their self-tests passed, but are not live acceptance.
- Backlog 0003 owns these native, permission-migration and cross-Mac checks.
